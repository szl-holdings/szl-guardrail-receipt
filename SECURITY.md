# Security Policy

## Reporting a vulnerability
Please do not open public issues for security problems. Use GitHub private vulnerability
reporting ("Security" tab -> "Report a vulnerability") or email security@a11oy.net.
We aim to acknowledge within 3 business days and to share a fix timeline within 10.

## Supported versions
Only the latest release / default branch is supported.

See also https://a11oy.net/.well-known/security.txt
